# API reference

The reference for every public type of the Bsft Foundation packages, generated from their XML
documentation. Namespaces follow the packages: `Bsft.Mediator` holds the mediator contracts,
and each package keeps its `AddBsft*`, `MapBsft*` and `UseBsft*` entry points in its own
`<Package>.DependencyInjection` namespace.

Which topic page explains a package is listed in [Packages](../../docs/packages.md).
